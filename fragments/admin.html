관리자 로그인

관리자 비밀번호를 입력해 주세요.

처음 한 번, Cloudflare에서 설정해 주세요

  1. D1 데이터베이스 만들기 — Cloudflare → 저장소 및 데이터베이스(Storage & Databases) → D1 → 데이터베이스 만들기, 이름 choisijun-db
  2. 홈페이지에 연결 — Workers 및 Pages → choisijun → 설정(Settings) → 바인딩(Bindings) → 추가 → D1 데이터베이스, 변수 이름 DB
  3. 관리자 비밀번호 — 같은 설정 화면 → 변수 및 비밀(Variables and Secrets) → 추가 → 이름 ADMIN_PASSWORD, 유형 비밀(Secret), 값은 12자 이상
  4. 다시 배포 — 배포(Deployments) → 가장 최근 배포 → 다시 시도(Retry deployment)

자세한 화면 순서는 저장소의 관리자-설정-가이드.md에 있습니다. 설정 전에도 문의하기는 메일 앱으로 받을 수 있습니다.

    방문자

      점선과 속이 빈 점은 아직 끝나지 않은 기간입니다. ◆ 는 운영 현황에서 그날 완료한 할 일 — 그래프 위에 손가락이나 마우스를 올리면 내용이 보입니다.

      사이트별

      숫자는 이렇게 셉니다
      • 방문자 — 사이트마다 다녀간 사람 수를 더한 값입니다. 같은 사람이 두 사이트를 보면 두 번 셉니다. 관리자 브라우저와 검색 로봇은 빠집니다.
      • 검색 유입 — 네이버·구글·다음·빙과 AI 검색에서 들어와 시작된 방문 수입니다. 검색 노출 작업의 효과를 볼 때 씁니다.
      • 문의 — 각 사이트 문의 저장소, 대신 받은 문의, 최시준 홈페이지 문의를 접수 시각 기준으로 셉니다.
      • 예약 이동 · 전화·카톡 — 예약 링크, 전화·카카오톡·메일 링크를 누른 횟수입니다.
      • 비교 — 어제와 그제처럼 끝난 기간끼리 비교합니다. 오늘·이번 주·이번 달은 진행 중이라 직전 기간의 같은 시점까지와 따로 비교합니다. 주는 월요일에 시작합니다.
