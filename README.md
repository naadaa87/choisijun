# 최시준 홈페이지 운영 안내

choisijun.com · 2026년 10월 최종본 (공간 레퍼런스 아카이브 최종본 · 검색 등록 반영)

HTML·CSS·JS로 만든 정적 사이트입니다. GitHub 저장소(`naadaa87/choisijun`)에 저장(Commit)하면 Cloudflare Pages가 1~2분 안에 자동으로 배포합니다. 따로 설치할 프로그램은 없습니다.

함께 들어 있는 안내서

- `GITHUB-배포가이드.md` — 이번 최종본 올리기, GitHub·Cloudflare 연결

## 2. 폴더 구조

```
choisijun/
├── index.html … 404.html      ← 완성된 페이지 19개 (gen.py가 만드는 결과물)
├── fragments/                 ← 페이지 본문 원본 — 글을 고칠 때는 여기
├── data/portfolio.json        ← 포트폴리오 공개 데이터
├── assets/                    ← 사진, 파비콘, 공유용 썸네일
│   └── video/                 ← 쇼릴 영상(1080p·720p)과 첫 장면 이미지
├── styles.css, script.js      ← 디자인 / 기능
├── gen.py                     ← 페이지 생성기 (검색 설정·sitemap·rss 포함)
├── search-verification.txt    ← 네이버·구글·빙 소유확인 코드 붙여넣는 곳
├── robots.txt                 ← 검색엔진 안내 (다음 인증 줄은 여기 맨 끝)
├── sitemap.xml, rss.xml       ← 검색엔진용 (자동 생성)
├── _headers                   ← 캐시·보안 설정, pages.dev 검색 차단
└── README.md 외 안내서 3개
```

## 3. 고치고 반영하는 방법

1. GitHub 저장소에서 고칠 파일을 열고 연필 아이콘(Edit) → 수정 → **Commit changes**
2. Cloudflare가 `python3 gen.py`를 실행해 페이지 19개와 sitemap·rss를 다시 만들고 배포합니다 (1~2분)
3. 시크릿 창에서 확인

알아둘 점

- 본문은 `fragments/` 안의 같은 이름 파일을 고치세요. 최상단의 `about.html` 같은 파일은 배포할 때마다 새로 만들어지므로, 그쪽을 고치면 다음 배포 때 덮어써집니다. 지역별 페이지는 fragments 파일이 없고 데이터에서 만들어집니다.
- Cloudflare 빌드 설정이 **Build command `python3 gen.py` / Build output directory `/`** 인지 한 번 확인해 주세요 (Pages 프로젝트 → Settings → Builds & deployments). 빌드 명령이 비어 있으면 `fragments/`, `data/`, `search-verification.txt` 를 고쳐도 반영되지 않습니다.
- 빌드가 실패해도 사이트는 직전 배포 상태로 그대로 유지됩니다. 실패 이유는 Deployments 탭의 로그에서 볼 수 있습니다.
- 페이지 안 링크는 `about.html` 처럼 써도 됩니다. 배포할 때 `/about` 형태로 바꿔 줍니다.

## 4. 포트폴리오 데이터 (`data/portfolio.json`)

### 무엇을 실었나

- 원본: 공간 레퍼런스 아카이브 최종본(2026-10-10) 338건
- **공간 244개 (카드 215장)** — 같은 건물의 개별 룸은 한 장으로 묶었습니다 (천안 흥파티 11실, 홍대 멀티룸 빌딩 6곳, 강화 올어바웃 5실 등).
- **공실개발·건물 기획 프로젝트 38건** — 공백·Core Mood·블랭크가 기획한 공실·건물 프로젝트. 지역·층·형태만 싣고 의뢰처와 건물명은 뺐습니다.

### 고치는 방법

- **작은 수정**(오타, 평수, 연도, 설명): GitHub에서 `data/portfolio.json` → 연필 아이콘 → Ctrl+F로 공간 이름 검색 → 값 수정 → Commit
- 글자는 큰따옴표 안에, 숫자는 따옴표 없이 씁니다. 값이 없으면 `null`.
- 공간 수, 시·도 수, 지도 색, 막대그래프, 필터 숫자, 지역별 페이지는 배포할 때 **자동으로 다시 계산**됩니다.
- 쉼표 하나만 빠져도 빌드가 멈춥니다. 이때도 사이트는 이전 상태 그대로이고, Deployments 로그에 몇 번째 줄이 문제인지 나옵니다.
- **큰 수정**(공간을 수십 개 추가하는 등)은 엑셀 아카이브를 먼저 고친 뒤 Claude에게 전달해, 지금과 같은 기준으로 JSON을 다시 만드는 편이 안전합니다.

포트폴리오 목록은 주소로 공유할 수 있습니다. 예: `choisijun.com/portfolio?brand=플레이션#pf-archive`, `choisijun.com/portfolio-seoul#area-홍대`

## 5. 검색 설정 (네이버·구글·다음)

등록 순서는 **`검색등록-가이드.md`** 에 있습니다. 홈페이지에 들어 있는 설정은 이렇습니다.

- 페이지마다 다른 제목·설명·검색어, 대표 주소(canonical), 카카오톡·SNS 공유 미리보기
- 구조화 데이터: 인물(최시준)·회사(㈜블랭크)·브랜드·쇼릴 영상·전자책·FAQ·이동 경로·공간 목록
- `sitemap.xml`·`rss.xml` 자동 생성, robots.txt 에 위치 안내
- `choisijun.pages.dev` 는 검색에서 제외 (`_headers`)
- 소유확인 코드: `search-verification.txt` 에 `naver =`, `google =`, `bing =` 뒤로 태그를 붙여넣으면 모든 페이지에 들어갑니다
- 다음(카카오) 인증 줄: `robots.txt` 맨 끝에 붙여넣습니다

검색어를 바꾸고 싶다면 `gen.py` 의 `PAGES` 에서 각 페이지의 `title`(제목), `desc`(설명), `keywords`(검색어)를 고치면 됩니다.

## 6. 쇼릴 (`assets/video/`)

| 파일 | 용도 |
|---|---|
| `showreel-2026-1080.mp4` | 데스크톱 (1920×1080, 약 3.7MB) |
| `showreel-2026-720.mp4` | 모바일 (1280×720, 약 1.6MB) |
| `showreel-poster.jpg` | 재생 전 첫 화면 |

- 메인: 화면에 절반쯤 보이면 소리 없이 자동 재생합니다. 방문자가 직접 멈추면 다시 자동 재생하지 않습니다.
- 미디어: 자동 재생 없이, 누르면 소리와 함께 재생합니다.
- 기기에서 '동작 줄이기'나 데이터 절약 모드를 켠 방문자에게는 자동 재생하지 않고, 영상도 미리 받지 않습니다.

영상을 바꿀 때: MP4(H.264), 파일 하나당 25MB 이하로 **새 이름**으로 올린 뒤 `fragments/index.html`·`fragments/media.html` 의 영상 주소(`data-src-lg`, `data-src-sm`, `<source src>`, `poster`)를 바꿉니다. `/assets/` 파일은 방문자 브라우저에 1년간 저장되기 때문입니다. 길이나 장면이 바뀌면 장면 버튼 `data-t`(초)와 `gen.py` 의 `VIDEO`(`uploadDate`, `duration`)도 맞춰 주세요.
