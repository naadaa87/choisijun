관리자 로그인

관리자 비밀번호를 입력해 주세요.

처음 한 번, Cloudflare에서 설정해 주세요

  1. D1 데이터베이스 만들기 — Cloudflare → 저장소 및 데이터베이스(Storage & Databases) → D1 → 데이터베이스 만들기, 이름 choisijun-db
  2. 홈페이지에 연결 — Workers 및 Pages → choisijun → 설정(Settings) → 바인딩(Bindings) → 추가 → D1 데이터베이스, 변수 이름 DB
  3. 관리자 비밀번호 — 같은 설정 화면 → 변수 및 비밀(Variables and Secrets) → 추가 → 이름 ADMIN_PASSWORD, 유형 비밀(Secret), 값은 12자 이상
  4. 다시 배포 — 배포(Deployments) → 가장 최근 배포 → 다시 시도(Retry deployment)

자세한 화면 순서는 저장소의 관리자-설정-가이드.md에 있습니다. 설정 전에도 문의하기는 메일 앱으로 받을 수 있습니다.
